How NexusScore Works

We replace the traditional credit file with a living, breathing financial graph — updated in real time from India's open finance ecosystem.

1
MSME gives one-time consent via Account Aggregator framework.
2
We auto-pull GST returns, UPI flow, EPFO, and bank statements without manual paperwork.
3
Neo4j Graph Engine maps supplier-buyer-transaction networks to detect hidden supply-chain risk.
4
ML Scoring Engine (XGBoost) computes a 300–900 multidimensional Financial Health Score.
5
IDBI loan officers see a Traffic Light Dashboard and approve credit in seconds.

Key Features

Every feature is designed to close the financial inclusion gap for India's MSMEs.

🔄
Alternate Data Ingestion
Automated parsing of GSTIN returns, UPI volume, and EPFO stability via the Account Aggregator framework — zero paperwork.
📊
Multidimensional Scoring
ML-weighted score (300–900) across cash flow, supply chain health, statutory compliance, and UPI transaction velocity.
🚦
Visual Risk Dashboard
Clean Traffic Light UI for IDBI loan officers with instant drill-down into specific risk signals and anomalies.
🕸️
Supply Chain Graphing
Identifies if an MSME is over-reliant on a single failing buyer by mapping B2B transaction graphs in Neo4j.
⚡
OCEN Integration
API-ready for the Open Credit Enablement Network — enabling seamless one-click loan origination and disbursement.
🔮
Predictive Risk
Predicts future cash-flow crunches using ML models on live UPI velocity — enabling proactive intervention before defaults occur.
